----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------# password-strength-checker
Begginer python cybersecurity project that checks the strength of the password entered to it

what it does:
it checks for atleast 8 digit characters
an uppercase letter
a special character
a number 
if the password does not meet the above requirements, then it tells the user what is missing in it . and asks them to enter a new password

basic password security concepts
